# DSE Mensuration revision

F6 HKDSE Mathematics (Compulsory Part) revision on Mensuration, for a 40-minute lesson.

- `Paper 1/`, `Paper 2/`: the DSE mensuration questions from 2012 to 2026, with solutions, in LaTeX.
- `Materials/`: what was built from them. Revision notes, a worksheet of twin questions with an answer copy, a
  self-study web page with a randomised MC drill, and a live lesson for the classroom TV.
  See [`Materials/README.md`](Materials/README.md) for the files and the 40-minute run sheet.

Open `Materials/site/index.html` (students) or `Materials/site/live.html` (teaching) in a browser.
